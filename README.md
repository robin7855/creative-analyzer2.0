# 광고 소재 효율 분석 도구

고효율 광고 이미지와 저효율 광고 이미지를 나란히 넣고, 생성형 AI로 차이점/개선점을 분석하는 간단한 웹 도구입니다.

## 실행 방법

정적 파일이라 로컬 서버로 바로 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 접속 후 아래를 입력하세요.

1. 좌측: 고효율 소재 이미지
2. 우측: 저효율 소재 이미지
3. OpenAI 호환 API Base URL / 모델명 / API Key
4. 필요 시 메모 입력
5. **AI 분석 실행** 버튼 클릭

## 참고

- 기본 API Base URL은 `https://api.openai.com/v1` 입니다.
- OpenAI 호환 API를 사용하는 경우 Base URL과 모델명을 해당 서비스 값으로 바꿔 사용하세요.
- API Key는 브라우저에서 직접 호출되므로, 내부망/개인 테스트 용도로 사용하세요.
